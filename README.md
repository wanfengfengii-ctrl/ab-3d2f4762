# 脉冲记录器偏移复核台

只有本地时标的多台脉冲记录器，逐对校时得到的观测约束可能拼不出任何一致的真实时间解释。本工具是一个 **TypeScript + React 纯前端复核台**（不调用任何业务后端）：导入或编辑模型后一键审计，并点选偏移端点查看完整见证。

## 模型与裁决

- 模型：2–24 台唯一编号记录器（恰一台 `reference: true`，偏移恒 0）、至多 128 个全局唯一编号事件、至多 256 条观测。
- 非参考机偏移为整数闭区间 `[offsetMin, offsetMax]`；本地时标与所有界值绝对值 ≤ 10⁹；同一记录器事件按列出顺序时标严格递增。
- 观测连接**不同**记录器的发送/接收事件；真实时刻 = 本地时标 + 偏移，真实接收 − 真实发送必须落在非负整数延迟闭区间 `[delayMin, delayMax]`。
- 非法编号、时标、界值、引用全部定位反馈（如 `events[2]（编号 11）`）；输入任何变更立即清除旧裁决。
- 求解：整数差分约束（Bellman-Ford）。
  - **可行**：给出各偏移的紧确最小/最大值，及每个端点的完整可行赋值（全体最小/全体最大赋值同时达到所有同类端点）；全部范围为单点 ⇒ 唯一解，否则多解。
  - **不可行**：给出闭合约束链，各上界同向相加 telescope 后总和严格小于零（0 ≤ 和 < 0 的矛盾）。
  - 点选任一端点：查看约束见证链、全部记录器偏移赋值（含逐事件真实时刻验算）与每条观测的实际延迟逐项核对。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run typecheck  # 代码检查
npm run test       # 单元 + 随机枚举对照测试
npm run build      # 产出 dist/
```

## Docker 运行

```bash
# 启动静态站点（宿主机端口可配置，默认 8080）
docker compose up -d web
HOST_PORT=9090 docker compose up -d web

# 一次性复核：代码检查 → 单元裁决 → 构建 → HTTP 冒烟（裁决与静态资源）
docker compose up --build verify
echo $?          # 0=通过；10/20/30/40 分别对应代码/裁决/构建/冒烟失败
```

- `web`：nginx 静态站点，内置 `/healthz`，Compose 健康检查通过后视为就绪。
- `verify`：一次性服务，依赖 `web` 健康后运行 `scripts/verify.sh`，自行退出并以退出码报告结果。
